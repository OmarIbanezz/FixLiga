# FixLiga
FixLiga (Sistemas y Soluciones Deportivas FixLiga S.A.S) es una plataforma web cuyo objetivo es generar automáticamente fixtures deportivos —eliminación directa, fase de grupos y sistema suizo— y simular torneos, reduciendo el tiempo y los errores de la organización manual en colegios, barrios, clubes y competencias profesionales.
